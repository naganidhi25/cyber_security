# 🎣 Phishing Attack Simulation Project

## 📌 Overview
This project demonstrates a **phishing attack simulation** conducted in a controlled and ethical environment. The goal is to understand how phishing attacks work and analyze user behavior when exposed to such threats.

A fake phishing email and a login page were created to mimic real-world scenarios. The responses of participants were recorded and analyzed to measure awareness levels.

---

## 🎯 Objectives
- Understand phishing techniques  
- Simulate a phishing email attack  
- Analyze user behavior  
- Suggest preventive measures  

---

## 🛠️ Project Components

### 📧 1. Phishing Email
- Fake email designed to look legitimate  
- Includes urgency-based message  

### 💻 2. Fake Login Page
- Built using HTML, CSS, and JavaScript  
- Mimics a real login interface  
- Displays a simulation message on submission  

### 📊 3. Data Analysis
- Click statistics  
- Data entry attempts  
- Phishing detection rate  

### 📸 4. Screenshots
- Email simulation  
- Login page  
- Output popup  
- Graphs (Pie chart & Bar graph)

## 📈 Results

| Metric | Value |
|--------|------|
| Click Rate | 70% |
| Data Entry Rate | 40% |
| Detection Rate | 50% |

👉 These results show that many users are vulnerable to phishing attacks due to lack of awareness.

## 🔍 Key Learnings
- Users trust urgent emails easily  
- Lack of awareness increases risk  
- Simple phishing techniques are effective  
- Awareness can reduce attacks significantly  

---

## 🛡️ Preventive Measures

### 🔐 Technical
- Spam filters  
- Multi-Factor Authentication (MFA)  
- Antivirus software  

### 👨‍💻 User Awareness
- Avoid suspicious links  
- Verify sender identity  
- Check email authenticity  

### 🏢 Organizational
- Security training  
- Phishing simulations  
- Strong security policies
